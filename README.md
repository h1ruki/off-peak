# Off-Peak

## Did London stop commuting?

Off-Peak is a single-page Power BI portfolio project that examines how London's station
travel patterns have changed since 2019, using official Transport for London (TfL)
station-footfall data.

- **Primary tool:** Power BI Desktop (transformation, data model, DAX and report design)
- **Supporting tools:** VS Code and Git (documentation, validation scripts and project assets)
- **Source:** TfL station-footfall data

**Status:** Phase 0 — Data Audit

No analytical results are published in this repository yet.
